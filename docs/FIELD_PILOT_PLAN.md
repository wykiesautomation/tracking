# Five-Truck Field Pilot Plan

1. Select five representative trucks, electrical systems, tank types and routes.
2. Record exact tracker, board, modem, SIM, interface and firmware revisions.
3. Complete installation and fuel calibration before pilot start.
4. Operate each truck for at least the approved observation period, default 168 hours.
5. Reconcile GPS routes, stops, maximum speed, tracker gaps and fuel events daily.
6. Record every incident, false positive, missing upload, reconnect and field intervention.
7. Resolve all blocking incidents or reject the release.
8. Attach pilot evidence to checklist items PA-100 and PA-101.
